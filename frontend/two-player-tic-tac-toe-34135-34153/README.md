# two-player-tic-tac-toe-34135-34153

This workspace contains a React frontend for a retro-themed two-player Tic Tac Toe game.

Quick start:
- cd frontend
- npm install
- npm start

The app runs at http://localhost:3000, features a 3x3 grid, alternating turns, winner/draw detection, and a New Game button. Light theme accents: #3b82f6 (primary), #06b6d4 (success), #64748b (secondary).
